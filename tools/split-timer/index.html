How to Use the Split / Lap Timer

Press Start to begin timing. During a run or activity, press the Lap (Split) button after each segment to record a split. Each lap entry shows the split time (duration of that lap only) plus the overall elapsed time and delta from previous lap. After 2+ laps, the fastest lap is highlighted in green and the slowest in red. Use "Copy Laps" to export all split times to your clipboard. Press Reset to start fresh.

  • Keyboard Shortcuts: Spacebar = Start/Pause, L = Record Lap, R = Reset
  • Projector Mode: Use fullscreen mode for lap display on classroom boards.

Split Timer Use Cases

  • Running & Swimming: Track lap times with automatic fastest/slowest identification.
  • Speedcubing: Record consecutive solve times with delta to see improvement.
  • Interval Training: Time each work/rest interval and compare across sets.
  • Quiz Competitions: Time each question and compare response speeds.
